# 빅플래너파트너스 · BigPlanner Partners

상업시설의 반복 문의를 건물 매뉴얼로 안내하고, 현장 확인이 필요한 민원은 담당자가 이어받을 수 있도록 정리합니다.

BigPlanner Partners' AI tenant service desk uses building manuals to answer routine questions and records requests that facilities staff need to follow up across shifts.
